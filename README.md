# P2 DESK

클콩 영상제작본부 **제작2파트 파트장용 데스크톱 비서**.
타임트리처럼 캘린더를 열고 날짜를 찾아 들어가는 과정 없이, 실행하면
**오늘 해야 할 일이 먼저** 보이도록 만들었습니다.

> Good Plan, Better Contents.

## 화면 다섯 개

| 화면 | 하는 일 |
|---|---|
| **Today** | 주간 시간표 + 오늘 일정 + **나만 보는 체크리스트** |
| **Calendar** | 월 / 주 / 일 보기, 팀원별 필터 |
| **Projects** | 프로젝트별 기획 → 촬영 → 편집 → 피드백 → 완료 진행 현황 |
| **My Tasks** | 날짜별 체크리스트, 요일 루틴, 최근 2주 기록 |
| **Team** | 팀원 오늘 상황과 이번 주 배정 현황 |

### 이 프로그램만의 것

- **My Checklist** — 팀 공용 일정과 별개로, 나만 보는 그날의 체크리스트입니다.
  타임트리와 가장 크게 다른 점입니다.
- **못 끝낸 일 자동 이월** — 어제 체크 못 한 항목이 오늘로 넘어옵니다. (설정에서 끌 수 있음)
- **요일 루틴** — "월요일: 주간 제작 현황 정리" 같은 고정 업무가 해당 요일에 자동으로 깔립니다.
- **팀원 상태 자동 추론** — "지금 촬영 중 · 대구" 같은 상태를 손으로 입력하지 않습니다.
  그날 일정에서 뽑아냅니다.
- **담당자 미지정 경고** — 담당이 비어 있는 일정을 Team 화면에서 따로 모아 보여줍니다.

## 실행

```bash
npm install     # 처음 한 번
npm start       # 앱 실행
```

### 설치 파일 만들기

```bash
npm run dist:win    # 윈도우 (.exe 설치본 + 무설치 포터블)
npm run dist:mac    # 맥 (.dmg, Apple Silicon + Intel)
```

`release/` 폴더에 나옵니다. **윈도우와 맥이 같은 코드에서 빌드됩니다.**

> 브라우저에서 `app/index.html` 을 그냥 열어도 동작합니다. 이때는 데이터가
> 브라우저 저장소에 저장되고, 저장 폴더를 지정할 수 없습니다.

## 맥북과 함께 쓰기

모든 데이터는 **JSON 파일 하나**(`part2-data.json`)에 들어 있습니다.

1. 윈도우에서 **설정 → 데이터 저장 위치 → 저장 폴더 바꾸기**
2. 구글 드라이브 · iCloud Drive · OneDrive · Dropbox 같은 **동기화 폴더**를 선택
   (기존 데이터는 자동으로 옮겨집니다)
3. 맥북에서도 같은 앱을 설치하고, 같은 폴더를 지정

이러면 회사 윈도우에서 적은 일정과 체크리스트가 집 맥북에서 그대로 이어집니다.
서버도, 계정도, 인터넷 연결도 필요 없습니다.

⚠️ 두 기기에서 **동시에** 편집하면 나중에 저장한 쪽이 이깁니다. 한 번에 한 곳에서 쓰세요.

### 나중에 실시간 동기화가 필요해지면

팀원 4명이 같이 쓰게 되는 순간이 오면 서버를 붙이면 됩니다. 그때 고칠 곳은
`app/js/store.js` 의 **두 함수뿐**입니다.

```js
async load()    // 데이터 읽기
async flush()   // 데이터 쓰기
```

화면 코드는 이 두 개만 부르기 때문에, 나머지는 손대지 않아도 됩니다.

## 타임트리 · 구글 캘린더 연동

**설정 → 캘린더 연동** 에서 `.ics` 파일로 주고받습니다.

- **내보내기** → 타임트리나 구글 캘린더에서 가져오면 팀에 공유됩니다
- **가져오기** → 타임트리에서 내보낸 `.ics` 를 넣으면 기존 일정이 그대로 옮겨옵니다
  - 제목·메모에서 팀원 이름을 찾아 **담당자를 자동으로 연결**합니다
  - "촬영", "편집", "시사" 같은 단어로 **종류도 자동 분류**합니다
  - 이미 가져온 일정은 다시 넣어도 중복되지 않습니다

체크리스트는 나만 보는 것이라 `.ics` 에 포함되지 않습니다.

## 단축키

| 키 | 하는 일 |
|---|---|
| `Ctrl` `N` | 일정 빠르게 추가 |
| `Ctrl` `Shift` `N` | 할 일 빠르게 추가 |
| `Ctrl` `1`–`5` | 화면 이동 |
| `/` | 검색 |
| `T` | 오늘로 이동 |
| `←` `→` | 이전 / 다음 기간 |
| `Esc` | 창 닫기 |

빠른 추가는 **제목만 적고 Enter** 를 눌러도 저장됩니다.

## 폰트

Pretendard 가 설치되어 있으면 자동으로 쓰입니다. 없으면 각 OS 기본 한글 폰트
(맑은 고딕 / Apple SD Gothic Neo)로 내려갑니다.

앱에 내장하려면 [Pretendard](https://github.com/orioncactus/pretendard) 의
`PretendardVariable.woff2` 를 `app/fonts/` 에 넣으면 됩니다. 폰트가 설치되지 않은
윈도우 PC에서도 같은 모양으로 보입니다.

## 데이터와 백업

| | |
|---|---|
| 저장 위치 | 설정 화면에 경로가 표시됩니다 |
| 자동 백업 | 데이터 폴더의 `backups/` 에 하루 한 번, 최근 14개 보관 |
| 수동 백업 | 설정 → 백업 → 전체 백업 내보내기 |

저장은 임시 파일에 쓰고 교체하는 방식이라, 저장 중에 앱이 꺼져도 원본이 깨지지 않습니다.

## 구조

```
electron/
  main.js       창·메뉴·파일 입출력 (Node 쪽)
  preload.js    화면과 Node 사이의 얇은 다리
app/
  index.html
  styles.css    디자인 토큰이 :root 에 모여 있습니다
  js/
    util.js     날짜 계산 · DOM 헬퍼
    store.js    데이터 모델과 저장소  ← 동기화 방식은 여기만 바꾸면 됩니다
    ics.js      타임트리 · 구글 캘린더 연동
    io.js       파일 저장/열기 (앱·브라우저 양쪽)
    ui.js       공용 조각 (일정 행, 체크리스트, 모달, 토스트)
    timegrid.js 주간/일간 시간표
    editor.js   빠른 추가 · 상세 편집
    icons.js    인라인 SVG 아이콘
    app.js      셸 · 화면 전환 · 단축키
    views/      Today / Calendar / Projects / My Tasks / Team / Settings
```

## 디자인

"Apple Calendar 가 영상 제작팀용 업무 관리 프로그램으로 발전한 것" 을 기준으로 잡았습니다.

- 배경 `#F7F7F8` · 카드 `#FFFFFF` · 글자 `#1D1D1F` · 경계선 `#E8E8EA` · 포인트 `#3478F6`
- 그림자를 거의 쓰지 않고 **여백과 얇은 선**으로 구분합니다
- 팀원 색은 전부 파스텔 톤이고, 일정 카드 전체를 칠하지 않고 **왼쪽 3px 바에만** 넣습니다
  (SK 파랑 · JH 초록 · SB 주황 · JY 보라 · 개인 그래파이트 · 중요 마감 레드)
- 간트차트, KPI 그래프, 복잡한 통계는 넣지 않았습니다
