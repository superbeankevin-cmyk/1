# P2 DESK

클콩 영상제작본부 **제작2파트 파트장용 데스크톱 비서**.
타임트리처럼 캘린더를 열고 날짜를 찾아 들어가는 과정 없이, 실행하면
**오늘 해야 할 일이 먼저** 보이도록 만들었습니다.

> Good Plan, Better Contents.

## 처음 실행하기

컴퓨터를 잘 모르셔도 됩니다. 순서대로만 하시면 됩니다.

**1. Node.js 설치** (처음 한 번만)

[nodejs.org](https://nodejs.org) 에서 왼쪽 **LTS** 버튼을 눌러 내려받고,
옵션은 건드리지 말고 계속 `다음`만 누르면 됩니다.

**2. 코드 내려받기**

[여기서 ZIP 파일을 내려받고](https://github.com/superbeankevin-cmyk/1/archive/refs/heads/claude/elegant-hypatia-hqbtyn.zip)
압축을 풉니다.

**3. 실행**

압축 푼 폴더 안에서 쓰는 컴퓨터에 맞는 파일을 더블클릭합니다.

| | |
|---|---|
| 윈도우 | **`실행하기 (윈도우).bat`** |
| 맥 | **`실행하기 (맥).command`** |

처음에는 준비 작업 때문에 2~5분 걸리고, 그 다음부터는 바로 켜집니다.
검은 창이 같이 뜨는데, 앱이 켜져 있는 동안 필요하니 닫지 마세요.

> 맥에서 **"확인되지 않은 개발자"** 라며 안 열리면, 파일을 마우스 오른쪽
> 클릭 → `열기` 를 누르세요. 한 번만 하면 됩니다.

### 매번 검은 창 없이 쓰고 싶다면

**`설치파일 만들기 (윈도우).bat`** 또는 **`설치파일 만들기 (맥).command`** 를
더블클릭하면 `release` 폴더에 진짜 프로그램이 나옵니다.

| 윈도우 | |
|---|---|
| `P2 DESK Setup 1.0.0.exe` | 설치해서 쓰는 버전. 바탕화면에 아이콘이 생깁니다 |
| `P2 DESK 1.0.0.exe` | 설치 없이 바로 실행되는 버전. USB에 넣어 다녀도 됩니다 |

| 맥 | |
|---|---|
| `P2 DESK-1.0.0-arm64.dmg` | Apple Silicon (M1 이후) |
| `P2 DESK-1.0.0.dmg` | Intel 맥 |

> 처음 열 때 윈도우는 **"Windows가 PC를 보호했습니다"**, 맥은
> **"확인되지 않은 개발자"** 경고가 뜹니다. 개발자 서명을 안 넣어서 그런 것이니
> 윈도우는 `추가 정보` → `실행`, 맥은 앱을 오른쪽 클릭 → `열기` 를 누르면 됩니다.
> 각각 한 번만 하면 다음부터는 안 물어봅니다.

**맥용 설치파일은 맥에서, 윈도우용은 윈도우에서 만들어야 합니다.**
서로 만들어 줄 수는 없습니다.

## 화면 다섯 개

| 화면 | 하는 일 |
|---|---|
| **Today** | 주간 시간표 + 오늘 일정 + **나만 보는 체크리스트** |
| **Calendar** | 월 / 주 / 일 보기, 팀원별 필터 |
| **Projects** | 프로젝트별 기획 → 촬영 → 편집 → 피드백 → 완료 진행 현황 |
| **My Tasks** | 날짜별 체크리스트, 요일 루틴, 최근 2주 기록 |
| **Team** | 팀원 오늘 상황과 이번 주 배정 현황 |

### 이 프로그램만의 것

- **My Checklist** — 팀 공용 일정과 별개로, 나만 보는 그날의 체크리스트입니다.
  타임트리와 가장 크게 다른 점입니다.
- **못 끝낸 일 자동 이월** — 어제 체크 못 한 항목이 오늘로 넘어옵니다. (설정에서 끌 수 있음)
- **요일 루틴** — "월요일: 주간 제작 현황 정리" 같은 고정 업무가 해당 요일에 자동으로 깔립니다.
- **팀원 상태 자동 추론** — "지금 촬영 중 · 대구" 같은 상태를 손으로 입력하지 않습니다.
  그날 일정에서 뽑아냅니다.
- **담당자 미지정 경고** — 담당이 비어 있는 일정을 Team 화면에서 따로 모아 보여줍니다.

## 명령어로 실행 (터미널이 편하다면)

```bash
npm install         # 처음 한 번
npm start           # 앱 실행

npm run dist:win    # 윈도우 (.exe 설치본 + 무설치 포터블)
npm run dist:mac    # 맥 (.dmg, Apple Silicon + Intel)
```

`release/` 폴더에 나옵니다. **윈도우와 맥이 같은 코드에서 빌드됩니다.**
맥용은 맥에서, 윈도우용은 윈도우에서 만드는 것이 가장 확실합니다.

> 브라우저에서 `app/index.html` 을 그냥 열어도 동작합니다. 이때는 데이터가
> 브라우저 저장소에 저장되고, 저장 폴더를 지정할 수 없습니다.

## 맥과 윈도우 함께 쓰기

모든 데이터는 **JSON 파일 하나**(`part2-data.json`)에 들어 있습니다.
그 파일을 클라우드 폴더에 두고 양쪽에서 같은 폴더를 가리키면 끝입니다.

**설정 → 데이터 저장 위치** 를 열면 그 컴퓨터에 있는 동기화 폴더
(iCloud Drive · 구글 드라이브 · OneDrive · Dropbox)를 **알아서 찾아 버튼으로 보여줍니다.**
누르면 그 안에 `P2 DESK` 폴더를 만들고 기존 데이터를 옮겨 줍니다.
맥에서도 같은 폴더를 고르면 끝입니다.

서버도, 계정도, 인터넷 연결도 필요 없습니다.

### 양쪽에서 고쳐도 안 날아갑니다

한쪽에서 파일이 바뀌면 **앱이 알아서 다시 읽어옵니다.** 창을 껐다 켤 필요가 없습니다.

양쪽에서 동시에 고친 경우에도 덮어쓰지 않고 **항목 단위로 합칩니다.**

| 상황 | 결과 |
|---|---|
| 맥에서 A 추가, 윈도우에서 B 추가 | 둘 다 남습니다 |
| 한쪽에서 지움 | 지워진 채로 남습니다 (되살아나지 않음) |
| 양쪽에서 **같은 항목**을 고침 | 나중에 고친 쪽이 남습니다 |
| 지운 뒤 다른 기기가 그 항목을 고침 | 되살립니다 (작업을 잃지 않는 쪽으로) |

일정·할 일·프로젝트·팀원·메모 전부 같은 규칙으로 합쳐집니다.

### 나중에 실시간 동기화가 필요해지면

팀원 4명이 같이 쓰게 되는 순간이 오면 서버를 붙이면 됩니다. 그때 고칠 곳은
`app/js/store.js` 의 **`load()` 와 `flushToFile()` 두 함수뿐**입니다.
합치는 규칙(`mergeData`)은 서버를 붙여도 그대로 씁니다.

## 타임트리 · 구글 캘린더 연동

**설정 → 캘린더 연동** 에서 `.ics` 파일로 주고받습니다.

- **내보내기** → 타임트리나 구글 캘린더에서 가져오면 팀에 공유됩니다
- **가져오기** → 타임트리에서 내보낸 `.ics` 를 넣으면 기존 일정이 그대로 옮겨옵니다
  - 제목·메모에서 팀원 이름을 찾아 **담당자를 자동으로 연결**합니다
  - "촬영", "편집", "시사" 같은 단어로 **종류도 자동 분류**합니다
  - 이미 가져온 일정은 다시 넣어도 중복되지 않습니다

체크리스트는 나만 보는 것이라 `.ics` 에 포함되지 않습니다.

## 폰트

**Pretendard 가 앱에 내장되어 있습니다.** 따로 설치할 게 없고, 폰트가 깔리지 않은
윈도우 PC에서도 맥과 똑같은 모양으로 보입니다.

`app/fonts/PretendardVariable.woff2` (2.0MB) 한 벌이 45~920 굵기를 전부 커버합니다.
[Pretendard](https://github.com/orioncactus/pretendard) v1.3.9, SIL Open Font License 1.1
(라이선스 전문은 `app/fonts/PRETENDARD-LICENSE.txt`).

다른 폰트로 바꾸려면 `app/styles.css` 맨 위의 `@font-face` 와 `--font` 두 곳만
고치면 됩니다. 폰트 파일을 지우면 각 OS 기본 한글 폰트로 자연스럽게 내려갑니다.

## 데이터와 백업

| | |
|---|---|
| 저장 위치 | 설정 화면에 경로가 표시됩니다 |
| 자동 백업 | 데이터 폴더의 `backups/` 에 하루 한 번, 최근 14개 보관 |
| 수동 백업 | 설정 → 백업 → 전체 백업 내보내기 |

저장은 임시 파일에 쓰고 교체하는 방식이라, 저장 중에 앱이 꺼져도 원본이 깨지지 않습니다.

## 구조

```
electron/
  main.js       창·메뉴·파일 입출력·변경 감시 (Node 쪽)
  preload.js    화면과 Node 사이의 얇은 다리
app/
  index.html
  styles.css    디자인 토큰이 :root 에 모여 있습니다
  fonts/        Pretendard (내장)
  js/
    util.js     날짜 계산 · DOM 헬퍼
    store.js    데이터 모델 · 저장소 · 기기 간 합치기(mergeData)
    ics.js      타임트리 · 구글 캘린더 연동
    io.js       파일 저장/열기 (앱·브라우저 양쪽)
    ui.js       공용 조각 (일정 행, 체크리스트, 모달, 토스트)
    timegrid.js 주간/일간 시간표
    editor.js   빠른 추가 · 상세 편집
    icons.js    인라인 SVG 아이콘
    app.js      셸 · 화면 전환 · 단축키
    views/      Today / Calendar / Projects / My Tasks / Team / Settings
```

## 디자인

"Apple Calendar 가 영상 제작팀용 업무 관리 프로그램으로 발전한 것" 을 기준으로 잡았습니다.

- 그림자를 거의 쓰지 않고 **여백과 얇은 선**으로 구분합니다

  (SK 파랑 · JH 초록 · SB 주황 · JY 보라 · 개인 그래파이트 · 중요 마감 레드)
- 간트차트, KPI 그래프, 복잡한 통계는 넣지 않았습니다
